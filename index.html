Partie 0 · Connaître

La chaîne et ses indices

Chaque caractère occupe une case numérotée. La numérotation commence à 0.

Cliquez sur une case ci-dessus.

Attention à la dernière case Long(ch) compte les caractères ; le dernier indice vaut Long(ch)-1. Écrire ch[Long(ch)], c'est désigner une case qui n'existe pas.

Long(ch) compte aussi les espaces. La chaîne vide "" a une longueur de 0.

Partie 0 · Connaître

La concaténation et l'accumulation

res ← ""
Pour i de 0 à Long(ch)-1 Faire
    res ← res + ch[i]
Fin Pour
Comparer les deux ordres Basculez le bouton : res + ch[i] recopie, ch[i] + res inverse. Même boucle, résultat opposé.

On part toujours de res ← "" : la chaîne vide est le zéro de la concaténation, comme 0 l'est pour l'addition. Et il n'existe pas d'opérateur − sur les chaînes — pour retirer, il faudra Effacer.

Pour coller un nombre à une chaîne, il faut le convertir d'abord : "Note : " + Convch(15).

Partie 0 · Connaître

La fonction Pos : rechercher une position

Le premier paramètre est la chaîne recherchée, le second la chaîne dans laquelle on cherche. La fonction rend un indice.

Deux erreurs fréquentes 0 est une position valide — on teste Pos(…) ≠ -1, jamais Pos(…) > 0. Et Pos rend un entier, jamais un booléen.

Essayez Pos("Z", "NABEUL") : aucune fenêtre ne correspond, la fonction rend -1. Essayez Pos("N", "NABEUL") : elle rend 0 dès la première comparaison — d'où le piège.

Conséquence utile : Pos(ch[i], ch) = i signifie « ce caractère n'est jamais apparu avant l'indice i ». C'est le test des caractères distincts, en une ligne.

Atteindre les chiffres d'un entier

Un nombre n'a pas d'indices. On le convertit en chaîne, et chaque chiffre devient une case.

somme des chiffres de n
m ← Convch(n)
s ← 0
Pour i de 0 à Long(m)-1 Faire
    s ← s + Valeur(m[i])
Fin Pour
Estnum n'accepte que des chiffres Ni signe, ni point décimal, ni chaîne vide. On l'appelle avant Valeur, jamais après : c'est le garde-fou.

Partie 0 · Connaître

Sous_chaine et Effacer : deux résultats complémentaires

Les mêmes bornes séparent la chaîne en trois morceaux. Sous_chaine prend celui du milieu, Effacer prend les deux autres.

Effacer(ch, d, f)  =  Sous_chaine(ch, 0, d) + Sous_chaine(ch, f, Long(ch))
À retenir pour la suite Trois cas suffisent à tout faire : Sous_chaine(ch, 0, k) = le début · Sous_chaine(ch, k, Long(ch)) = la fin · Effacer(ch, 0, k) = la fin, encore. En séance 4, k ne sera plus un nombre écrit à la main : ce sera Pos(sep, ch).

Partie 1 · Valider

Le principe du drapeau booléen

La fonction doit répondre Vrai ou Faux. Trois décisions à prendre.

1 · Par quoi commencer ?

Par l'optimisme : ok ← Vrai. On suppose la chaîne correcte, puis on cherche à se faire contredire. Un seul intrus suffit à faire tomber le drapeau.

2 · Quelle boucle ?

On veut s'arrêter dès le premier intrus : inutile de lire la fin d'une chaîne déjà refusée. Le nombre de tours n'est donc pas connu → Tant que, avec le drapeau dans la condition.

3 · Comment avancer ?

Si le caractère convient, on passe au suivant : i ← i + 1. Sinon, on baisse le drapeau : ok ← Faux. Jamais les deux — c'est un Si … Sinon.

Pourquoi jamais les deux Si on incrémentait i aussi dans le cas d'échec, la boucle continuerait à avancer alors que la réponse est déjà connue. Le drapeau baissé arrête le parcours et fige l'indice sur le caractère fautif.

Ce qu'il ne faut surtout pas écrire à la place : un break, ou un Retourner à l'intérieur de la boucle. Le drapeau est la sortie propre.

Cas particulier : la chaîne vide


  
Testez ch = "" dans la simulation. La fonction répond Vrai.


  
ch ← ""     →   Long(ch) = 0
                Tant que (0 < 0) Et Vrai   →   Faux dès le départ
                le corps de la boucle n'est jamais exécuté
                Retourner ok    →   ok vaut toujours Vrai


  
Ce n'est pas un bug de l'algorithme : la fonction répond exactement à la question posée. « Tous les caractères sont-ils des majuscules ? » — sur zéro caractère, il n'y a aucun contre-exemple. La réponse Vrai est logiquement correcte.


  

    La règle
    Une vérification « tous les caractères sont… » accepte toujours la chaîne vide. Si la chaîne vide n'est pas acceptable, c'est au contrôle de saisie de l'écarter — pas à la fonction.
  


  
Jusqu'à (Long(ch) ≥ 1) Et Verif_Maj(ch)


  
Le même raisonnement vaut pour une longueur imposée. Un code d'agence de trois lettres : (Long(ch) = 3) Et Verif_Maj(ch). La fonction reste inchangée — on ne la modifie pas pour chaque cas particulier, on compose les conditions dans le Jusqu'à.

Partie 2 · Découper

  
Extraire le premier bloc

  
La borne n'est plus un nombre écrit à la main : c'est la position du séparateur.


  
ch = "ALI BEN SALAH"        sep = " "

Pos(sep, ch)                     → 3
Sous_chaine(ch, 0, Pos(sep, ch))  → "ALI"
Effacer(ch, 0, Pos(sep, ch) + 1)  → "BEN SALAH"


  

    Le résultat d'une fonction devient l'argument d'une autre
    Pos calcule où couper, Sous_chaine prend le bloc, Effacer retire le bloc et son séparateur : c'est le rôle du + 1. Sans lui, le séparateur resterait en tête et le bloc suivant serait vide.

L'algorithme du parcours par blocs


  

    
Procédure Ranger (ch : Chaîne de caractères, @T : Tab, @n : Entier)
DEBUT
    ch ← ch + " "
    n ← 0
    Tant que ch ≠ "" Faire
        p    ← Pos(" ", ch)
        T[n] ← Sous_chaine(ch, 0, p)
        n    ← n + 1
        ch   ← Effacer(ch, 0, p + 1)
    Fin Tant que
FIN
